# 🚗 Car Rental System

A simple terminal-based car rental system written in **C++**, created as my **first major programming project**.

---

## 📚 About the Project

This project was built **from scratch** as a **semestral assignment** for the *Programming in C++* course at university. It handles various aspects of a rental service, including:

- Managing cars, users, and rental contracts  
- Handling car availability, service status, and archiving  
- Organizing data via file I/O  
- Command-line based interface with basic error handling

---

## 📄 Additional Materials

This repository also includes:

- 📘 **Programmer and user documentation**  
- 🧪 **Testing data** for verification and validation  
- 💻 **Windows and Linux builds** for easy execution
